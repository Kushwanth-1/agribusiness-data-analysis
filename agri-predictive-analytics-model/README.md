# Agri Predictive Analytics Model

This folder organizes the Week 6 Yuva Intern project deliverables.

## Project
Forecast district-level crop yield at the end of agricultural week 20 and explain the main drivers for procurement planning in a fictional Nagpur agritech scenario.

## Data transparency
The internship brief did not provide a dataset. The project therefore uses a seeded synthetic dataset of approximately 350,000 weekly records across six districts and six crops. Results demonstrate the workflow only; they are not official or observed Vidarbha agricultural statistics.

## Reported evaluation
The report states test MAE of approximately 1.19 q/ha per district-crop and a 31% improvement over the three-year rolling-mean baseline. It also explicitly reports that the test error is about 40% higher than validation error, so the stability criterion was not met.
